<objective>
Fix the backend so that document listings return an absolute `archivo_url` field (not just the relative `archivo` path), and add `es_version_actual` filter support to the DocumentosDigitalesViewSet.

Purpose: The frontend's `DocumentInfo` type expects `archivo_url` to show "Ver documento" button. The `DocumentosDigitalesSerializer` currently exposes only `archivo` (DRF returns a relative path). Without `archivo_url`, the guard `existingDoc.archivo_url` is always falsy and the button never appears.

Secondary: The `subir_documento` response in `OnboardingViewSet` must also return `archivo_url` so the upload response matches `UploadDocumentResponse` type.

Output: Updated serializer with `archivo_url` SerializerMethodField, `es_version_actual` filter, and updated subir_documento response.
</objective>

To get absolute URL: `request.build_absolute_uri(doc.archivo.url)` — needs request context.

Pattern for SerializerMethodField needing request:
```python
def get_archivo_url(self, obj):
    if obj.archivo:
        request = self.context.get('request')
        if request:
            return request.build_absolute_uri(obj.archivo.url)
        return obj.archivo.url
    return None
```

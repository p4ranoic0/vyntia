## What Was Built

**GAP-01 — Routing guard for completed employees:** Added `OnboardingGuard` component to `App.tsx` that wraps the `/onboarding` route. When a completed employee navigates directly to `/onboarding`, the guard redirects them back to `/`. The existing `OnboardingRoute` (wrapping Dashboard) still redirects in-progress employees TO `/onboarding`. These are complementary guards.

**GAP-03 — Wrong API URL:** `OnboardingEmployeePage.tsx` was calling `/api/v1/rrhh/legajo/` (404 endpoint). Fixed to `/api/v1/rrhh/documentos-digitales/` with correct axios params object `{ params: { empleado, es_version_actual: 'true', page_size: 50 } }`. Also fixed the response unwrapping chain to handle paginated APIResponse shape (`raw?.data?.results ?? raw?.data ?? raw?.results`).

`onboardingDataService.getConstanciasTrabajo` had the same wrong URL — fixed to `/api/v1/rrhh/documentos-digitales/` with `es_version_actual: 'true'` added.

**GAP-04 — Stale document UI after mutations:** All mutation `onSuccess` handlers now invalidate `['legajo-docs', empleadoId]` so the document list in `OnboardingEmployeePage` refreshes immediately after any upload, create, or delete in any tab. `DocumentUploadZone` invalidates the broader `['legajo-docs']` key (no empleadoId in scope) which React Query matches via partial-key invalidation.

# Phase 01.1 Plan 03: Ver Documento Button and View-Only Modal Summary

**One-liner:** Added `isViewOnly` prop to DocumentPreviewModal and "Ver documento" ghost button to DocumentUploadZone info card so employees can preview previously uploaded documents without triggering the upload flow.

## What Was Built

### Task 1 — DocumentPreviewModal isViewOnly prop
- Added `isViewOnly?: boolean` to `DocumentPreviewModalProps` interface (default `false`)
- When `isViewOnly=true`: the "Enviar documento" confirm button is hidden via conditional render
- When `isViewOnly=true`: the cancel button label changes from "Cancelar" to "Cerrar"
- All existing call sites (upload preview flow) are unaffected — they omit `isViewOnly`

### Task 2 — Ver documento button in DocumentUploadZone
- Added `isViewOpen` state alongside existing `isPreviewOpen` state
- In the info card return block (when `existingDoc && !showReplace && !localOverrideEmpty`):
  - Wrapped the return in a React fragment to host the view modal as a sibling
  - Added `DocumentPreviewModal` with `isViewOnly=true`, `archivoUrl=existingDoc.archivo_url`, opening via `isViewOpen` state
  - Added "Ver documento" ghost button — only rendered when `existingDoc.archivo_url` is truthy
  - Buttons grouped in a flex row alongside the existing "Corregir y reenviar" / "Reemplazar" buttons
- Button has `type="button"` to prevent form submission
- Existing upload/replace/preview-before-upload flows are unchanged

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed EmpleadoPermission.write_roles missing canonical role names**
- **Found during:** Task 2 RED phase — tests got 403 PermissionDenied instead of failing on missing fields
- **Issue:** `EmpleadoPermission.has_permission` checked `write_roles = ["admin", "rrhh", "supervisor"]` but the system's canonical role name is "Administrador RRHH" (lowercased: "administrador rrhh"). The RRHHPermission base class handles it correctly but the EmpleadoPermission override was too narrow.
- **Fix:** Extended write_roles to `["admin", "rrhh", "supervisor", "administrador rrhh", "analista rrhh", "jefe de area"]`
- **Files modified:** back/api/v1/rrhh/permissions.py
- **Commit:** 8ea32b78

**2. [Rule 1 - Bug] Fixed LocMemCache test bleed in test class**
- **Found during:** Task 1 GREEN phase — tests 4 and 5 failed when run together (cached stale GET responses)
- **Issue:** `@cache_response` decorator caches responses; Django's `LocMemCache` used in tests doesn't support wildcard deletes so `@invalidate_cache` patterns don't clear entries. Subsequent GET calls returned cached pre-PATCH data.
- **Fix:** Added `autouse=True` `clear_cache` pytest fixture that clears cache before/after each test
- **Files modified:** back/tests/test_empleado_update_v2.py
- **Commit:** 715d8fc4

## Decisions Made
- Used Controller for Radix Select fields — Radix Select does not forward ref to native input, so register() alone does not work with react-hook-form
- initialValues typed as `Record<string, unknown>` to avoid creating a redundant typed interface for a pass-through prop (data comes from backend, shape validated at runtime)
- AFP conditional uses watch() — reactive without extra state
- OnboardingSectionStatus compact grid layout (2 cols mobile, 4 cols desktop) keeps it above tabs without excessive height
